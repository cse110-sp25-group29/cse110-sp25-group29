### Discussion Notes:
#### Music Card Game Idea - Vincent:
1. **Cloud Storage**: Use cloud storage to address the song storage problem.
2. **Normalize Songs**: Normalize songs available on YouTube for volume consistency.
3. **User Playlists**: Possibly create a pipeline to allow users to add their own playlists.
4. **API Dependency**: Question for Shelby: Does writing our own API count as a dependency (though we need to interact with the YouTube API anyway)?
5. **Spotify API**: Question: Does the Spotify API allow exporting album covers?
6. **Multiplayer**: Game could eventually support multiplayer (starting with single-player implementation first).
7. **Extra Stats**: Can include extra stats like favorite artists based on high scores.

#### Business Card Idea - Aarav:
1. **Different Card Types**: Can be expanded to include various types of cards, e.g., business cards, persona cards, recipe cards, and more.
2. **Camera API**: Question for Shelby: Can we use Camera API for scanning cards?
3. **Mobile App**: Focus on building a mobile app rather than a web app.
4. **Simplify**: Needs to be distilled to one or fewer types of cards to make it more useful.

#### Credit Card Idea - Arnav:
1. **Manual Input**: Users need to enter everything manually, which feels cumbersome.
2. **Expense Tracker**: More of an expense tracker than a "card" app.
3. **Lack of Differentiation**: Difficult to differentiate from existing apps due to limitations.
4. **Security**: Needs good security features to protect sensitive personal financial data.
5. **Web Scraping**: Question for Shelby: Can we use web scraping (since other ideas might need APIs too)?

#### Playing Card Idea - Hugo:
1. **Overdone**: The concept is overdone, with millions of similar games available online.
2. **Similarity to Warm-Up Exercise**: Very similar to our warm-up exercise.
3. **UI Importance**: Key takeaway—having a fast and efficient website with a good user interface is crucial.

#### Trading Card Idea - Arnav:
1. **Marketplaces**: Most existing apps are primarily marketplaces for trading cards.
2. **Game Focus**: We can focus on creating a game where players can build their own teams.
3. **1v1 Battles**: Allow users to engage in 1v1 battles with their teams.
4. **Merge with Persona Cards**: Merge the persona card idea to let users create custom personas of their favorite players.
