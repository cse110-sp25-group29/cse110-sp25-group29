# CSE110-Group29 CONCARD

This is a full-featured project for designing, previewing, editing, and managing custom cards using HTML, CSS, and JavaScript.

---

## Project Structure

```
source/
├── assets/
│   ├── icons/                # SVG & PNG icons
│   ├── images/               # images
│   ├── scripts/              # All JavaScript modules
│   │   ├── homepage.js
│   │   ├── editor-page.js
│   │   ├── view_all_card.js
│   │   └── ...
│   ├── styles/               # CSS files
|   ├── editor-page.html      # Editor Page HTML file
|   ├── homepage.html         # Home Page HTML file
|   └── view_all_card.html    # View All Card Page HTML file
|
└── documentation.md          # Documentation
```
