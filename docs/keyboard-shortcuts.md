## Keyboard Shortcuts
Use the following keyboard shortcuts to efficiently interact with elements on the business card canvas:

### Transformations

- **Shift (while resizing):**
    Locks the aspect ratio of the selected object when resizing using the mouse.
  
- **Arrow Keys (↑ ↓ ← →):**
    Move the selected object in the corresponding direction.
  
- **Shift + Arrow Keys:**
    Move the selected object with finer, more precise increments.
  
### Layer Management

- **Cmd + Arrow Up / Down (↑ ↓):**
    Change the layer ordering of the selected object:
    - Cmd + Up-arrow (↑): Bring object forward
    - Cmd + Down-arrow (↓): Send object backward
  
### Object Deletion
- **Delete / Backspace:**
  Removes the currently selected object from the canvas.
  
### Saving
- **Ctrl + S:**
  Saves the current state of the card.
